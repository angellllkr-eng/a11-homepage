Skill contract

A good skill tells the agent when to stop.

Every capability should expose its inputs, allowed tools, prohibited actions, expected artefacts, and validation method.

  • Allowed tools and access boundary.
  • Required inputs and privacy boundary.
  • Expected output and evidence record.
  • Validation command and handoff condition.
