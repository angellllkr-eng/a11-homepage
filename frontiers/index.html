Frontier primitives

More capability should create more clarity.

Agent capability is useful when its boundaries are visible. A11 treats reasoning, tool use, and evidence as separate surfaces that can be inspected before the next consequential step.

01

Reason

Interpret context, compare options, and prepare a decision without presenting preparation as execution.

02

Act

Expose carefully bounded tools with explicit identity, authority, version, and idempotency requirements.

03

Prove

Return the evidence trail needed to inspect what happened and what remains blocked.

Controlled autonomy

Let the system move quickly. Keep the decision legible.

A11 does not make uncertainty disappear. It gives uncertainty a visible place in the operating model so people can decide what happens next.

  • Suggestions remain advisory until an authorised handoff.
  • State-changing actions require a defined authority boundary.
  • Stale decisions are rejected rather than silently applied.
  • Unknown runtime state is labelled unknown, not live.
